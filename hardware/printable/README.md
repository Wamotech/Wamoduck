# Printable releases / 可打印发布

This directory contains print-oriented derivatives with an explicit scope, printer target, units, and validation record. Files under [`hardware/step`](../step/) and [`models/wmduck/meshes`](../../models/wmduck/meshes/) are reference geometry and simulation assets; their presence does not make them print-ready robot parts.

本目录收录明确注明用途、目标打印机、单位与验证记录的打印衍生文件。[`hardware/step`](../step/) 与 [`models/wmduck/meshes`](../../models/wmduck/meshes/) 分别是参考几何和仿真资产，不能因文件存在就视为可直接打印的机器人零件。

| Package / 包 | Output / 输出 | Target / 目标 | Status / 状态 |
| --- | --- | --- | --- |
| [Wamoduck A1 mini standing display](wamoduck-a1mini-standing/README.md) / [Wamoduck A1 mini 站立摆件](wamoduck-a1mini-standing/README_打印说明.md) | One fixed 160 mm model / 160 mm 一体固定模型 | A1 mini, PLA, 0.4 mm nozzle, 0.16 mm layers, tree supports / A1 mini、PLA、0.4 mm 喷嘴、0.16 mm 层高、树状支撑 | Geometry and digital slicing verified; physical print not tested / 已完成几何与数字切片检查，尚未实物试打 |

The standing display is decorative and nonfunctional. All joints are fused and cannot move. It is not a replacement for the robot's structural parts, motors, bearings, electronics, or assembly documentation.

站立模型是非功能性展示摆件，所有关节均已融合且不可运动；它不能替代机器人的结构零件、电机、轴承、电子部件或装配资料。
