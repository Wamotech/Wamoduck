# Wamoduck 默认站立 · A1 mini 单色打印版

优先用 Bambu Studio 打开 **Wamoduck_A1mini_PLA_160mm.3mf**。该文件包含一体模型、A1 mini 打印配置和已生成的支撑/切片；也提供 **Wamoduck_Standing_160mm.stl** 供自行设置。

## 模型

- 外形尺寸：前后 **73.86 mm**、左右 **97.58 mm**、总高 **160.00 mm**，包含约 3.5 mm 厚的一体底座。
- 姿态：仓库 `models/wmduck/wmduck.urdf` 的全部 15 个活动关节取 `q=0`，与当前 CAD 默认站立姿态一致。
- 保留头部、眼部凹槽、鸭嘴、机身、电机外形、倾斜颈部及弯曲双腿。
- 所有关节固定并合成一个连续实体；隐藏位置加入约 4.8 mm 直径连接销，薄壁表面适度加厚，合并装配间隙和封闭内腔。双脚连接到薄底座。
- 删除无厚度的内部 IMU 曲面；细小紧固孔、装配缝及内部结构经过简化。嘴缝、外壳轮廓及主要机械特征尽量保留。
- 这是固定摆件，各关节不可活动。保留 100% 导入尺寸可维持当前补强后的厚度。

## 已保存的切片设置

| 项目 | 设置 |
| --- | --- |
| 打印机 | Bambu Lab A1 mini |
| 喷嘴 | 0.4 mm |
| 耗材 | 单卷 Generic PLA，任意单色，不需要 AMS |
| 打印板 | Textured PEI Plate / 纹理 PEI 板 |
| 层高 | 0.16 mm，首层 0.20 mm |
| 墙数 | 3 |
| 填充 | 15% Gyroid / 螺旋体 |
| 支撑 | 自动树状支撑，与模型同一种 PLA |
| 支撑接触 | 顶部 Z 间距 0.20 mm，接口 3 层 |
| 裙边 | 外侧 8 mm |
| 喷嘴 / 热床 | 220°C / 65°C（Generic PLA 预设） |

底座朝下，按保存朝向放在打印板中央。头部下方、鸭嘴和机身有悬垂，**保留树状支撑**。打印后先拆外围支撑，再小心处理颈部、腿部和鸭嘴附近的接触点。

本次 Bambu Studio 02.08.02.60 实际切片：**1000 层，约 11 小时 57 分钟，PLA 约 150.26 g（含支撑等切片用料），0 次换色**，未返回切片警告。模型、支撑和裙边的首层整体占用约 **96.47 × 116.92 mm**，距打印板边缘至少约 31.5 mm。时间和用料为切片估算，实打会随机器与耗材有所变化。

预览颜色仅代表单个耗材槽；实际颜色取决于装入的线材。若使用其他 PLA、喷嘴或打印板，在 Bambu Studio 中选择对应预设后重新切片。

## 重新生成

`source/build_model.py` 是几何生成脚本，`source/requirements.txt` 固定所需 Python 包。脚本需要保留本文件夹与仓库的相对位置，并依赖原始 URDF 及配套 STL。

```powershell
python -m pip install -r source/requirements.txt
python source/build_model.py build
python source/build_model.py render
```

`slicing/` 保存本次使用的拓竹官方预设展开副本和离线切片脚本；重新生成 STL 后须重新切片，已保存的 3MF 切片不会自动更新。

A1 mini 的官方成型范围为 180 × 180 × 180 mm：[拓竹官方规格](https://asia.store.bambulab.com/en/products/a1-mini)。
